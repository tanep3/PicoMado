# 対応するハード構成

`profile.txt` が機種の組合せを選び、`config.h` は Wi-Fi、接続先、個体 ID、接続したパネルの有無など個体ごとの設定を持ちます。プロファイルは `firmware/profiles/` にあります。新しい配線でも、対応する表示器・入力構成であれば別名のプロファイルを作ってビルドできます。

| プロファイル | MCU | 画面 | 入力 | 状態 |
| --- | --- | --- | --- | --- |
| `pico_w_lcd_160x80_4` | Pico W | ST7735S、160×80、RGB565 | 4 ボタン | 既存 LCD 実機で確認済み |
| `pico_w_eink_250x122_0` | Pico W | 2.13 インチ V4 E-ink、250×122 | 0 ボタン | E-ink_0 表示を確認済み |
| `pico_w_eink_250x122_2` | Pico W | 同上 | 2 ボタン | 動作確認済み |

Pico 2 W、ESP32、別サイズの画面、未実装のボタン数・操作、スピーカー、マイク、サーボには実装追加が必要です。同じ画面とボタン数で配線を変える場合は別の profile を作れます。[カスタマイズガイド](customization.md)で変更場所と検証の進め方を確認してください。使用する配線と画面の型番を確認してから作業し、通電したまま配線を変更しないでください。

## 適合条件と接続

以下は追跡済み `firmware/profiles/*.h` の GPIO 定義です。GP 番号は Pico W の GPIO 番号で、コネクタの端子名とは異なります。画面の電源・GND は必須ですが、モジュールごとの電源端子名と許容電圧はこのプロファイルに定義されません。購入した画面の仕様書で電圧・端子配列を確認し、Pico W の適切な電源と共通 GND へ接続してください。仕様が不明なモジュールは通電しないでください。

| LCD 160×80 ST7735S、4 ボタン | Pico W 側 |
| --- | --- |
| 画面 CS / SCK / MOSI / DC / RESET | GP17 / GP18 / GP19 / GP20 / GP21 |
| 画面 BLK（配線する場合） | GP22。個体設定の `PM_LCD_BLK_CONNECTED` と極性を実配線に合わせる |
| SUB / UP / POWER / DOWN ボタン | GP12 / GP13 / GP14 / GP15。押すと共通 GND につながる配線 |
| 画面の電源 / GND | モジュール仕様書に従う電源 / Pico W と共通 GND |

| 2.13 インチ V4 E-ink 250×122、0／2 ボタン | Pico W 側 |
| --- | --- |
| 画面 CS / SCK / MOSI / DC / RESET / BUSY | GP9 / GP10 / GP11 / GP8 / GP12 / GP13 |
| 2 ボタン構成の UP / DOWN | GP20 / GP21。押すと共通 GND につながる配線 |
| 0 ボタン構成 | ボタン配線なし |
| 画面の電源 / GND | V4 モジュールの仕様書に従う電源 / Pico W と共通 GND |

E-ink の V3、別寸法、別ドライバは適合確認されていません。0 ボタン構成は本体ボタンで表示を切り替えられません。画面をまだ接続しない検証では `PM_EINK_PANEL_CONNECTED=0` とし、その状態を表示の成功と扱いません。

個体設定で変えてよいハード項目は、LCD のバックライト接続有無と極性（`PM_LCD_BLK_CONNECTED`、`PM_LCD_BLK_ACTIVE_HIGH`）、E-ink パネルの接続有無（`PM_EINK_PANEL_CONNECTED`）だけです。画面寸法、制御器、SPI とボタンの GPIO はプロファイルが所有します。旧形式の設定も有効な定義が完全一致する場合だけ受け入れ、再定義は拒否します。

個体設定とプロファイルのハード定義は平坦です。`#if` などの条件分岐、および一切の `#include` は許しません。新形式はビルドが追跡済みプロファイルを絶対パスで強制読込し、旧形式は自身の平坦な定義をプロファイルと照合します。この制限により通常ビルド・診断ビルドで異なるハード GPIO が有効になるのを防ぎます。

筐体の設計データは同梱されていません。選んだ画面・ボタン・配線に合う筐体を用意するか、自分で設計してください。
