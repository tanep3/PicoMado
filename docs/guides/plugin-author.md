# 小さなプラグインから始める

[最小例](../../service/examples/minimal-plugin.rs)は黒一色の LCD 画像を返す、保存や外部通信のないプラグインです。現在のサーバには登録されておらず、公開版の機能として動作するものではありません。例のテストは一時的な Cargo target を使い、サービス・実機を起動しません。

1. `Plugin` が ID と対応端末能力、純粋な候補規則を示します。`ContentPlugin` が状態、入力計画、画素を所有します。両者の ID は一致させます。
2. `PluginSet::register` で規則と内容を一組にします。実際に公開版へ組み込むときは `service/src/plugins.rs` の `builtins()` と `DEFAULT_ORDER` を更新し、設定・保存互換性を契約へ記録します。例の `main` はその登録 API だけを試します。
3. 入力を使うなら `plan` に規則を定義します。外部取得やファイル IO は純粋な計画内で行わず、既存のジョブ・executor 境界を使います。`current_frame` の LCD は 160×80、RGB565BE で 25,600 byte です。E-ink は別の形式と能力検証が必要です。
4. 端末のボタン操作、世代、ACK の扱いは共通基盤に残します。新しい画面や MCU への対応をこの例から推測しないでください。サーバのプラグイン追加も変更 ID、契約、root gate、独立レビューを経ます。
