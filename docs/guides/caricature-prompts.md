# 風刺画のプロンプトを編集する

情報取得プロンプトと作画テイストの候補は、風刺画の通常画面にある **「詳細設定」→「情報取得プロンプト・作画テイストを管理」** から管理します。管理画面の場所は `/plugins/caricature/prompts` です。通常画面には候補の選択だけを置きます。

管理対象を選んで「文面を編集」、または「新規追加」を押し、日本語の名前と指示文を入力して保存してください。保存した候補は次回生成用に選択されます。「削除」は確認欄に候補名を入力して確定します。選択中の候補を削除すると残った別の候補へ切り替わり、最後の1件は削除できません。削除した配布候補も再起動で復活しません。編集・追加・削除は既存の SQLite 状態へ永続保存し、再ビルド・再起動なしで次の生成に使います。進行中の生成の文面と、既存の作品・履歴は変更しません。名前は80文字以内、指示文は1200文字以内です。

各管理欄の「配布時のデフォルトを表示・コピー」を開くと、配布時の候補を選び、名前と文面を参照できます。指示文はコピー用ボタンか通常の選択・コピーで編集欄に貼り付けられます。この参照値はユーザーの編集・削除とは独立して保持し、削除した候補や新規候補にも利用できます。

共通の生成指示と見出し文は、次のフォルダ内のファイルで編集します。候補ごとの文面は上記の管理画面で扱い、ファイルとの二重管理にはしません。

`~/.config/PicoMado/caricature/data/prompt_templates/`

| ファイル | 用途 |
| --- | --- |
| `news.txt` | ニュースを調べるときの共通指示 |
| `image.txt` | 作画するときの共通指示 |
| `heading.txt` | 「画像に見出しを付ける」が ON のときに加える指示 |

各ファイルは最初の生成開始時に、存在しないものだけ作られます。既存ファイルは更新時も上書きしません。配布用の文面は日本語です。以前の版で作られた英語の `image.txt` はそのまま残るため、日本語に置き換えたい場合は配布用 `service/assets/caricature-image-prompt.txt` を参考にしてください。

見出しを試すときは **`heading.txt` を日本語の普通の文章で編集して保存**してください。例えば「画像の内容が伝わる短い日本語の見出しを、必ず画像内に書いてください。」のように書けます。配置や文字サイズを指定する必要はありません。アプリはこの文章を、選択中の作画テイストの末尾へ直接つなぎます。同じ文章がテイストに既に含まれる場合は重複させません。チェックが OFF のときは追加しません。ファイル末尾の改行や空白は連結時に取り除きます。

保存した変更は次に開始する生成から読み込まれ、再ビルドやサーバ再起動は不要です。自動生成、選択した題材からの作画、文章からの作画で共通です。進行中の生成と再試行は、開始時に保存した文面を使います。旧版で開始済みのジョブは元の見出し文を保持します。既存画像は再生成しません。

`news.txt` と `image.txt` の `{{...}}` は差し込み用の印です。名前を変えず、それぞれ一度ずつ残してください。

| ファイル | 必ず残す印 |
| --- | --- |
| `news.txt` | `{{topic}}`（題材）、`{{utc_time}}`（現在時刻）、`{{recent_sources}}`（既出の出典）、`{{feedback}}`（前回の問題） |
| `image.txt` | `{{style}}`（見出し指示を含む作画テイスト）、`{{brief}}`（ニュースまたは指定文章）、`{{work_dir}}`（保存先）、`{{feedback}}`（前回の問題） |

`heading.txt` には差し込みの印を使いません。全ファイルは UTF-8、各32KiB以内です。空の文章、印の誤り、文字コード不正などがある場合は直前に読み込めた正常版を使い、まだ正常版がなければ配布用の文面を使います。問題は Web の生成エラー欄に表示します。差し込んだ題材や文章内の印は再評価しません。`.last-good` で終わる退避ファイルと、各ジョブの `prompt-templates.json` はアプリ管理用なので編集しないでください。
