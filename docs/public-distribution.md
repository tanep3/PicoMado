# 公開候補の作成

元の `main` の履歴には過去のローカルパスや個体・ネットワーク観測が残ります。履歴は書き換えず、元リポジトリや非公開バックアップを公開物に含めません。

`python3 tools/export_public.py --out /非公開の新しいパス` は Git の追跡ファイルから公開用ソース・ガイド・素材・ライセンスを選び、個体設定、内部変更記録、観測記録と Git 履歴を除きます。既知の個体識別子を試験用の値に置換し、内部記録との照合も行います。新しいファイルは先に Git の追跡対象にしてください。出力はそのまま公開せず、内容・画像・第三者権利表示を確認してください。

確認後、出力ディレクトリをアーカイブにし、SHA256 を控えます。`__pycache__` などのローカル生成物や実設定を追加しません。manifest は内容確認の参考情報であり、ビルドや利用の条件ではありません。候補の生成だけでは公開や push を行いません。
