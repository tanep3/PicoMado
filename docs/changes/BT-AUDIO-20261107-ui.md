# BT-AUDIO-20261107 — ホーム端末UIの表示順と開閉保持（2026-11-08）

親変更 [BT-AUDIO-20261107](BT-AUDIO-20261107.md) のWeb UI調整。ユーザーは
Bluetoothスピーカーを常時表示し、端末別の接続・操作設定をその下の初期閉鎖の
折りたたみにすることを求めた。追加指摘は「端末の管理・削除を開くと、すぐに勝手に閉じる」。

## 原因と既存比較

2秒ごとの `refreshManaged` は状態を読み取り、`render` でmainのDOM全体を再作成する。
既存 `render` はBluetoothのdetailsだけ開状態を取得・復元する一方、管理・削除のdetailsは
保持していないため、開いても次の再描画で初期閉鎖へ戻る。端末設定をdetailsにするだけでは
同じ不具合を導入するため、既存の再描画前スナップショットを両detailsへ適用する。

## 実装前契約

- 各端末のBluetoothスピーカー領域は折りたたみ要素をやめ、設定と音量を常時表示する。
- 端末別の接続・操作設定はBluetoothの後、管理・削除の前のdetailsに入れる。新しいページでは初期閉鎖。
- 再描画直前の実DOMから開状態を読み、同じ端末ID・incarnation・領域のdetailsへ復元する。開く／閉じるの両操作を尊重し、端末間・設定／管理間・削除後の別incarnationへ状態を混ぜない。
- 開閉を保存するためにサーバAPIや永続設定を追加しない。Bluetooth操作、音量・ミュート、設定送信、削除確認と対象の内容は変えない。
- 無音DOM試験で表示順・初期閉鎖・常時表示、繰り返し自動更新、開閉を直接変更した直後の更新、端末独立・incarnation変更、設定保存と削除確認の対象を検証する。旧ソースで自動閉鎖の再現を確認する。
- 独立レビュー、本番適用、実画面確認、変更全体の終了判断は親が所有する。実音再生とファーム操作は行わない。
