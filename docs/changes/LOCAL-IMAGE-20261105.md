## Follow-up: uploaded image list and conversion jobs

The cause is that `LocalImageExecutor` was implemented but omitted from `plugins::executors()`. The shared worker therefore returned its generic unsupported failure before file scanning or conversion. Registering the executor at the composition boundary fixed this. A new test invokes the registered executor against a temporary uploaded image and verifies its scan result; the existing real-CLI test covers preparation and both device frames.
