## Follow-up: per-device static images

The existing selection stores one prepared image for all devices. Caricature uses `PluginContext.token.device_id` to choose per-device temporary artwork, validates a requested device through `CommandContext.devices`, and returns `RefreshTargets::Devices` for a targeted change. Local images should use the same boundaries. Keep the existing shared `selected` image as a fallback for saved installations; add durable device assignments and prepared frames so each LCD or E-ink can independently select an uploaded image. Conversion must continue producing both 160×80 RGB565 and 250×122 E-ink frames. The Web UI should present an explicit device choice when preparing an image and show each device's current assignment. A completed conversion may only assign the original device incarnation; deleting a device removes its assignment, and deleting an original removes its prepared frames and any assignments that reference it without touching other images. Verify independent simultaneous display, a newly added device, deletion, and state restoration in tests. This change remains local until a new service restart is authorized.
