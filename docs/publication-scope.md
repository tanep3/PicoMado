# 公開範囲と私的証拠

この作業ブランチ全体をそのまま公開しない。公開候補は英日 README、初回設定・対応表などの利用者ガイド、汎用設定例、必要なソースとライセンスである。公開前には配布する Git 履歴を含めて個人値を再監査する。現在の作業ブランチで Markdown の例示値を置換しても、旧コミットから元値を消したことにはならない。

以下は個人環境を指す値を含むため、元の証拠を保持したまま公開版から分離する対象である。

| 対象 | 役割 | 必要な扱い |
| --- | --- | --- |
| `docs/checkpoints/20261020/*.json`、`docs/checkpoints/20261021/*.json` | 採取時点のソース・成果物・保存先を結ぶ証拠 | 原本を私的に保全し、公開用には個人パスとネットワーク値を除いた別表現を作る |
| `docs/changes/*.json` の過去の検査記録への絶対パス | 変更段階と検査証拠を結ぶ参照 | 原本と証拠を保全し、公開用の参照関係を別途設計する。単純なパス置換で検査済みと称しない |
| 過去の Markdown 検証記録 | 時刻付き観測と判断 | 置換値が実測値でないことを各文書に示す。公開対象に含めるか再評価する |
| Git の既存履歴 | 旧版の上記ファイルを含む | 履歴改変や push はこの作業では行わない。公開方法は親が決める |

実験用の固定値を持つ試験・サンプルコードは汎用例へ移行中。新規利用者は [README](../README.md) と [初回設定](guides/first-setup.md)から入り、時刻付き記録を現在の手順として実行しない。
