# ローカル動画プラグイン要件（LOCAL-VIDEO-20261105）

## 目的と入力

YouTube に依存せず、手元のファイルを Web からアップロードして有限の動画を LCD 端末へ配信する。衛星動画は受入素材の一例であり、形式や UI を衛星専用にしない。原本をプラグイン専用の `data/imports/` に保存し、160×80 の JPEG フレームへ変換して再生する。ライブ配信、外部 URL、動的キー割当、実機操作は含めない。

## 操作と互換性

- 独立した `local-video` プラグインとして登録し、既存順序の末尾へ追加する。保存済み順序・端末別選択・有効化は共通カーネルの移行規則を使う。
- Web のファイル選択からアップロードし、保存済みファイルと出力 FPS を選んで準備する。2 fps を選択できる。原本のみの削除、準備済み動画の再生・停止・削除を扱う。原本削除後も変換済み動画は再生できる。変換操作は既存のプラグインコマンドと revision に従う。
- FPS は 1～30 の整数とし、音声は再生しない。アスペクト比を保って黒帯で 160×80 に収める。JPEG → RGB565 と端末への配信は既存の有限動画経路を使う。
- 共有再生時計、端末別の送信可否、古い表示世代の拒否、遅い端末向けの latest 配信は既存契約に従う。LCD 以外へ動画を送る保証は初版に設けない。
- ファイル名は単一の安全な名前に限定し、ディレクトリ指定、シンボリックリンク、特殊ファイルを拒否する。取り込みファイルを変換後に上書きしても、完成キャッシュは既存版として保つ。失敗・取消し時は以前の再生を維持する。
- アップロードは最大 512 MiB とし、上限超過と同名の既存ファイルを拒否する。ストリームで一時ファイルに受け、完了後に公開する。失敗や接続中断時は一時ファイルを削除する。
- 変換中は既存のジョブ経路で状態を表示する。変換完成後のキャッシュはプラグイン専用領域に保管し、他プラグインの資産を変更しない。

## 受入

2 fps MP4 を準備して最初と最後の有効フレームが読み出せること、無効ファイル名や symlink を拒否すること、複数端末の共有時計と世代判定を既存共通経路で保つこと、再起動後にキャッシュを検証して復元できることを自動テストする。端末の実描画 FPS・音声・物理操作は今回の自動テストの証明対象外。
