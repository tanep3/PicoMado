# PicoMado Bluetooth音声（検証中）

変更ID: BT-AUDIO-20261107。仕様正本は[変更記録](../changes/BT-AUDIO-20261107.md)。

各PicoMadoが、それぞれのBluetoothスピーカーへ接続する。母艦とスピーカーを直接ペアリングする構成ではない。A2DPで出力し、AVRCPの再生/一時停止、次、前のボタンをPicoMadoのSUB、DOWN、UPへ渡す。HFPとマイクは含まない。

## 使い方

1. Bluetooth対応ファームを入れた端末をサーバへ接続する。
2. WebUIホームの対象端末で「Bluetoothスピーカー」を開き、ONにする。
3. スピーカーをペアリング待ちにし、「周辺のスピーカーを探す」を押す。
4. 機器名とアドレスを確認して「この端末に接続」を選ぶ。探索範囲はそのPicoMadoの周辺。
5. ローカル音楽プラグインで変換済み音源を端末ごとに選んで再生する。

端末ごとの接続先/ON・OFFを保存する。探索結果と接続成功表示は一時的な状態で、再起動後に成功を偽装しない。未対応ファームは「対応ファームが必要」と表示する。探索だけではA2DP対応を断定せず、接続時に確認する。

## 検証用ビルド

既定ではBluetoothを組み込まない。既存のデバイス設定を使い、ビルド時だけ指定する。

```sh
PM_BLUETOOTH_AUDIO=ON firmware/tools/build.sh --device PicoMado-lcd1
PM_BLUETOOTH_AUDIO=ON firmware/tools/build.sh --device E-ink_0
```

ビルドは書込みではない。実機への書込みは既存手順に従う。フラグを省略したビルドはOFFへ戻る。

ON版は現行サーバの `frame-bytes-v1` binary画像配送が必要。旧サーバの大きな数値配列JSONフレームは対応対象外。音声処理と画像領域を同時に確保するため、旧JSONワークスペースだけを縮小している。画素数/画像品質は変更しない。

## 現時点の制約

- 実機出音、Wi-Fiとの連続運転、AVRCPボタン、再接続/鍵保持は未検証。LCD/E-inkのビルドとホスト試験だけで利用可能と断定しない。
- ローカル音楽は48kHz stereo。44.1kHzのみ対応するスピーカーは現段階では音声開始に失敗する。
- 音声不足は停止として扱い、古い音や欠落した音を黙って再生しない。接続状態と音声の正常再生は別の確認事項。
- YouTube/ローカル動画の音声と映像同期、ネットラジオはまだ接続していない。
- PIN入力が必要な従来機器は非対応。機器選択後のJust Worksペアリングのみ。
