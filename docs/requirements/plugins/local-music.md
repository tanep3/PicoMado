# ローカル音楽

WebUIで音源をアップロードし、端末ごとに別の曲を再生する。Bluetooth機器はホームの端末設定で接続する。

1. 「ローカル音楽」で MP3/WAV/FLAC/OGG/M4A/AAC をアップロード（256 MiB以下、2時間以内）。
2. 「再生用に変換」を押す。母艦のffmpegで48kHz・ステレオPCMに変換する。
3. 対象端末でローカル音楽チャンネルを選び、このページの端末別欄から曲と再生を選ぶ。
4. 一時停止は途中位置を保つ。停止は先頭に戻す。サーバ再起動後は自動再生しない。

一覧は全端末共通、選曲・再生操作は端末別。画面の「再生要求中」は音が出た証明ではない。Bluetooth接続状態と実音を確認する。削除は原本・変換キャッシュ・その曲の端末選択を対象とする。

PCMキャッシュは1秒192,000バイト（2時間で約1.38GB）を使用する。削除すると解放する。同名ファイルを上書きせず、先に削除するか別名で追加する。変換中の一時ファイルは処理終了・取消し時に整理する。

実装変更・検証状態は `docs/changes/MUSIC-PLAYER-20261107.md` を参照。Bluetooth配送は `BT-AUDIO-20261107` と連携する。
