# ローカル音楽

WebUIで音源をアップロードし、端末ごとに別の曲を再生する。Bluetooth機器はホームの端末設定で接続する。

1. 「ローカル音楽」で MP3/WAV/FLAC/OGG/M4A/AAC をアップロード（256 MiB以下、2時間以内）。
2. アップロード後に音声情報が自動登録される。「再生用に変換」は不要。再生欄は曲一覧の上に表示される。
3. 対象端末でローカル音楽チャンネルを選び、このページの端末別欄から曲と再生を選ぶ。
4. 一時停止は途中位置を保つ。停止は先頭に戻す。サーバ再起動後は自動再生しない。

一覧は全端末共通、選曲・再生操作は端末別。画面の「再生要求中」は音が出た証明ではない。Bluetooth接続状態と実音を確認する。削除は原本・変換キャッシュ・その曲の端末選択を対象とする。

再生時に母艦のffmpegで原本を48kHz・ステレオPCMへ逐次復号し、端末別音量の適用後、対応端末には交渉済みSBCで送る。新しい全曲PCMキャッシュは作らない。母艦にはffmpegとffprobeが必要。曲の秒数は音源情報による目安で、終端は実際の復号完了から決める。

同名ファイルは上書きせず、先に削除するか別名で追加する。各再生は原本の一時コピーと専用復号器を使い、停止・切替・切断・失敗で整理する。既存のPCMと原本は自動削除せず、PCMのみの旧曲も維持する。

起動・一時停止からの再開では、先頭から開始位置まで復号して捨てる処理が入るため待つ場合がある。初回は最大10秒、以後の読取りは100msまで。期限を超えると再生失敗を表示する。再生位置は確認済みの端末消費位置を使い、起動待ちやバッファ待ちを再生済み時間へ足さない。実際の音声出力にはさらにスピーカー側の遅延がある。
