## 内容と更新

既存の機能・例外・運用上の工夫を抽出して Rust プラグインとして再作成する。事前更新は共通運用要件に従う。既存本番は変更・移行しない。

既存ソース・実機動作の細目は未調査であり、U-01・U-09 で照合する。Python の構造をそのまま移植しない。初版ではサブ機能を設けず、サブ機能入力は無反応でよい。
