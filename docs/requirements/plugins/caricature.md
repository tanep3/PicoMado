# 風刺画プラグイン要件

[要件定義書の案内](../README.md)と[共通カーネル要件](../kernel.md)を参照する。共通の事前更新・鮮度・失敗表示は[プラグイン共通運用要件](../README.md#プラグイン共通運用要件)に置く。

## 内容と更新

既存の機能・例外・運用上の工夫を抽出して Rust プラグインとして再作成する。事前更新は共通運用要件に従う。既存本番は変更・移行しない。

ローカルの `PicoW_E-ink_Display/ai_news` にある既存ソースを 2026-10-12 に読み取り、[機能抽出・互換チェック](../../legacy-compatibility-checklist.md)に記録した。毎時・手動生成、履歴、PUSH と描画後 ACK を確認したが、既存 E-ink 製品の移行を決めたものではない。PicoMado 初版 LCD での作画方式・実表示と新プラグインの完全な機能差分は U-01・U-09 で検証する。Python の構造をそのまま移植しない。

端末で風刺画を表示中にサブメニューボタンを押すと履歴閲覧に入る。上で一つ古い作品、下で一つ新しい作品へ進み、最古・最新で止まる。電源ボタンは入る前に表示していた画像へ戻して閲覧を取り消す。サブメニューボタンをもう一度押すと、実際に表示中の作品を確定して通常表示に戻る。確定画像はその端末だけで次の自動生成まで表示し、共有の最新作品・履歴は変えない。閲覧中に新作品が追加されても作品 ID で位置を追い、開始画像と閲覧先を取り違えない。切断・再接続時は閲覧を解除する。

新規生成した作品は生成PNGの縦横をそれぞれ半分に縮小し、カラーの非可逆WebP品質90として不変アーカイブに保存する。奇数寸法は切り上げる。LCD向け160×80 RGB565は生成PNGから直接縮小し、E-ink向け250×122の1bit PNGは従来のDPIDと閾値で作る。保存WebPのハッシュ・復号・再読込を検証してアーカイブを確定するまで作業PNGを保持する。既存作品の原画は復元・移行しない。端末向けの変換結果は作品IDと原画ハッシュ、解像度、画素形式、処理設定、変換版を含むキーで交換可能なキャッシュに置く。既存作品の別解像度は保存済み白黒画像から変換する。新規作品の原画ファイルを失っても保存済み160×80/250×122画像の表示は可能とし、新たな解像度への変換は失敗を返す。サブモードの表示マークは端末への送信時に付け、原画と共有キャッシュには書き込まない。

保存期間は生成日の日本時間の暦日から3ヶ月とし、月末は存在する最終日に丸める。カレンダーで日付を選んで「削除プロテクトモード」に入り、複数の画像を選択して最下部の「チェック画像を削除しない」で保護できる。保護解除も可能とする。保護画像は解除まで期限削除の候補にしない。削除単位は作品にひもづく原画、画像入りアーカイブJSON、表示PNG、変換キャッシュ、風刺画のDB履歴であり、設定・プロンプト・端末情報は含めない。表示中・閲覧中の作品は削除しない。不可逆削除はビルド機能と実行環境変数の両方を有効にした場合のみ実行する。公開・永続化済み原画が確認できるジョブの作業フォルダだけを毎日整理し、実行中・再試行中・未保存成果を除外する。詳細は[保存と期限整理の設計](../../caricature-storage-retention.md)を参照する。

題材プリセットに「最新Yahooニュース」を加える。指示文は「24時間以内に発表された、知っておくべき日本のYahooニュースを1件選び、何が起きたかを要約してください。」とする。既存の題材・画風の候補と選択、生成・画像処理・再試行設定を保持し、保存済み状態からの起動時も追加候補を表示する。

Web の風刺画画面には日本時間の月間カレンダーを置き、前月・翌月への移動、日付ごとの件数と代表画像、選択日の全作品を表示する。最新作品と選択日の詳細画像には保存済みの半サイズカラーWebPを使い、WebPを持たない旧作品だけ保存済みPNGに戻す。カレンダーの小さな代表画像は表示用PNGを使う。作品にはニュース概要、出典 URL、カスタム文章、生成時設定を必要に応じて示し、生成時設定の展開状態は画面更新後も作品ごとに保持する。履歴から端末への一時表示は従来どおり共有最新作品を変更しない。ダークモードを維持し、画像処理・再試行・モデルは「詳細設定」に収める。

「画像に見出しを付ける」は保存可能なチェックボックスとし、初期値は OFF とする。ON のジョブの作画プロンプトに限り「一言なんの画像か見出しをそえてください。」を追加する。ジョブ受付時の設定を固定し、設定変更による既存作品の再生成は行わない。
