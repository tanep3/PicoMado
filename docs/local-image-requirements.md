# ローカル画像プラグイン要件（LOCAL-IMAGE-20261105）

Web で静止画像をアップロードし、選んだ画像を LCD と E-ink に表示する。既存のローカル動画と同様に元ファイルをプラグイン専用 data に保存し、選択中の変換結果をプラグイン状態として DB に保存する。元画像は明示的な確認付き削除のみ行い、その画像を表示中なら変換結果も解除する。既存ユーザーデータを自動削除しない。

## 表示

- LCD は 160×80 のカラー RGB565、E-ink は 250×122 の 1-bit 画像とする。現行ハードウェアプロファイルにない画面寸法は未対応として扱う。
- 「画面に収まる切り抜き」は、元画像の中心を画面と同じ縦横比になるまで左右または上下から切り抜き、その後ちょうど画面寸法へ縮小する **center crop / cover** と定義する。余白を付けず、顔や文字が端にある画像では欠ける可能性を UI に明示する。補間は Lanczos3、透過部分は白背景に合成する。
- E-ink 用の 250×122 画像を外部 `pic2gray4px` CLI に渡す。出力 PNG の寸法を再確認し、既存 `eink::from_png` によって転送形式へ詰める。PicoMado 内へ変換アルゴリズムを複製しない。変換 CLI が使えない場合はエラーにし、LCD のカラー結果を E-ink 用の完成物と偽らない。
- 画像の準備が失敗した場合は以前の表示を維持する。端末ごとの表示切替は既存のプラグイン選択と世代判定を用いる。

## ファイルと操作

- PNG/JPEG/WebP を受け付け、最大 20 MiB。危険なファイル名、シンボリックリンク、空ファイル、上限超過、同名ファイルの上書きを拒否する。
- ファイル選択、アップロード、一覧更新、画像選択・変換・表示、元画像削除、準備済み画像削除を Web から操作できる。削除時は対象を明示し、変換済み画像の削除で表示中なら停止する。
- 重い画像デコード、外部 CLI 実行、ファイル IO はアプリ共有ロックの外で行う。壊れた入力、CLI 失敗・タイムアウト、出力不正は復旧可能なエラーとして表示する。

## 配布

`pic2gray4px` の単一正本は公開リポジトリ https://github.com/tanep3/pic2gray4px とする。2026-11-05 現在 GitHub Release の配布バイナリは無い。PicoMado の公開物は `tools/export_public.py` による候補生成であり、正式な配布アーカイブや CI はまだない。PicoMado 側で固定版を手動更新して同梱する方式は採用しない。上流リリースを起点に、対応 OS/CPU の署名・チェックサム付き実行ファイルを公開し、PicoMado の配布物生成を自動起動する方式を目標とする。通常利用者に Git・Rust・別途インストールを要求しない。PicoMado のソースツリーに CLI のソースやビルド済みバイナリを追跡しない。上流 Release と自動配布工程が完成するまでは第三者での自動利用を達成済みと記載しない。
